Lab 6: Austin Hometown Interactive Map

This project combines a custom Mapbox basemap, a CSV dataset of meaningful Austin locations, and a Python-generated interactive map.

Interactive Map

Reflection

For my basemap design, I took inspiration from the colorful and creative vibe that Austin is known for, especially the look of Austin concert posters and the overall artsy feel of the city. I wanted the map to feel a little more stylized than a normal map while still being easy to read. I used warmer land colors and darker water tones so there would be clear contrast between different elements on the map. I also adjusted the roads and labels so they stood out but did not overpower everything else. My goal was to make something that visually matched the personality of Austin while still functioning like a real map people could use.

One of the biggest challenges while designing the basemap was figuring out how to make it work at different zoom levels. When I zoomed out, there were too many labels and features showing up, which made the map look really cluttered. I had to experiment with the style across zoom range settings in Mapbox so that certain things only appeared when the user zoomed in. For example, I made sure smaller roads and extra labels only appear when you are closer to the city. This helped keep the map readable whether someone is looking at the whole region or zooming into specific neighborhoods.

The coding part of the project involved using Python to turn my list of meaningful Austin locations into an interactive map. My script reads the CSV file that contains all the places I chose, sends the addresses to the Mapbox Geocoding API, and gets the latitude and longitude for each location. Then it uses Folium to place markers on the map using my custom Mapbox basemap. I also set up different marker colors depending on the type of location, like parks, restaurants, or recreation spots. Each marker has a popup that shows the place name, my description, and an image. I used AI to help me get the structure of the code started, but I worked through the sections to understand what they were doing so I could make changes if something was not working.

Overall, this project helped me see how design, data, and coding all connect when building an interactive map. It was interesting to combine a basemap that I designed in Mapbox with a dataset of places that are personally meaningful to me in Austin.
