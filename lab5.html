AI-Assisted Development

For this lab, I completed Experiment A (Portfolio Enhancement) and Experiment C (Debugging with AI). The goal was not just to generate code with AI, but to demonstrate that I can read, explain, and modify what it produces.

Experiment A: Portfolio Enhancement

Feature: Dark Mode Toggle

I added a dark mode toggle to my navigation bar. When clicked, the site switches between light and dark themes. I used AI to generate an initial version of the feature, then reviewed it line-by-line and adjusted both the structure and styling so it matched the layout of my portfolio.

How it works

  • JavaScript adds or removes a dark class on the <body>.
  • My CSS uses variables (such as --bg and --text) so that when the dark class is active, those values change.
  • The selected theme is saved using localStorage, so it persists across refreshes and page navigation.

Key Code Snippet (with Explanation)


/* When the body has the "dark" class,
   these variables override the default theme values.
   This is what visually changes the site colors. */
body.dark {
  --bg: #0f1115;
  --text: #f3f4f6;
}

/* This toggles the "dark" class on the body element.
   The CSS above responds to that class, so this line
   is what actually switches the theme on and off. */
document.body.classList.toggle("dark");

/* This stores the user's theme preference so the
   mode stays consistent after refresh or navigation. */
localStorage.setItem("site-theme", isDark ? "dark" : "light");

Modifications I Made

  • I adjusted the button styling so it aligned with my existing navigation design.
  • I ensured the theme persisted across pages using localStorage.
  • I added safeguards so the script does not break if the button is missing on a page.

Experiment C: Debugging with AI

During development, my page would not open correctly when previewing in VS Code. Instead of immediately rewriting code, I treated this as a debugging experiment.

What Was Happening

When attempting to preview the file, the browser either showed a blank page or failed to load properly. This occurred after I added the new JavaScript file for dark mode.

My Initial Hypothesis

Since the issue appeared after adding new functionality, I assumed the problem was related to how I linked the JavaScript file. I suspected the file path might not match my folder structure.

What AI Helped Me Verify

AI recommended checking the script tag path, confirming the file existed in the correct directory, and reviewing the browser console for errors. It also reminded me that file and folder names must match exactly, including capitalization.

The Fix


<!-- Correct script path placed before closing body tag -->
<script src="js/theme.js"></script>

What I Learned

  • Small file path mismatches can prevent a page from loading entirely.
  • Preview errors are often structural (linking issues), not logical issues.
  • Checking the console before rewriting code is more efficient.

My Guidelines for Using AI in Coding

  • I do not submit code that I cannot explain.
  • I review AI-generated code line-by-line before implementing it.
  • I test every change in the browser before committing.
  • I treat AI as a collaborator, not a replacement for understanding.
  • If I encounter something unfamiliar, I research it before keeping it.
