Austin Hometown Map

This project creates an interactive map of meaningful places from my hometown of Austin, Texas.

The map uses:
- A custom Mapbox basemap designed in Mapbox Studio
- Python with Folium
- Mapbox Geocoding API

Files included:
- hometown_map.py (Python script)
- hometown_locations.csv (dataset of locations)
- austin_hometown_map.html (interactive map output)

The script reads the CSV, geocodes the addresses, adds markers with symbols based on location type, and creates pop-ups with images and descriptions.
